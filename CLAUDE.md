# ksharma-website — Claude Code guidance

Personal website + portfolio for Karan Sharma. Plain static HTML on **GitHub Pages**,
served from `main` branch `/docs`. No framework, no build step (blog pages are
pre-generated). Live: https://ksharma-xyz.github.io/ksharma-website/ (custom domain
ksharma.xyz cutover is deferred).

## Hard copy rules (zero tolerance)

- **No em dashes (—) anywhere in copy. Ever.** Use a colon, comma, "to", or a clean
  short sentence. Keep sentences simple. (Also avoid the en dash for ranges; write "2022
  to 2024".)
- **Never publish Karan's personal Gmail address.** Public contact is **hey@krail.app**
  or a LinkedIn message (https://www.linkedin.com/in/ksharma-xyz/).
- Use real, accurate content only. Never invent metrics, roles, or links. The source of
  truth is `CONTEXT.md` (resume + GitHub).
- **Humble yet impressive.** Confident but never flashy or boastful. Let the facts carry
  it; no bravado or buzzwords (avoid things like "at scale", "done right", "the apps
  behind the day jobs"). State plainly what was built. The substance is impressive enough.

## Images

- **Always WebP.** Convert with `cwebp` (resize to the rendered size). No raw PNG/JPEG.
- Real assets live in `docs/assets/shots/` (portrait, app icons, app screenshots).
- App Store screenshots are preferred for app showcases when available; local/site
  assets are an acceptable interim (swap later).

## Structure

- `docs/index.html` — single-page site with five tab "pages" (Home, Apps, Portfolio,
  Blog, Photos). Tab routing is `data-page` + hash; see the inline `<script>`.
- `docs/assets/site.css` — all design tokens + components (extracted from the handoff).
- `docs/blog/<slug>/index.html` — static post pages, generated by
  `migration/generate-blog.mjs` from `migration/extracted/blog/*.md`.
- `docs/robots.txt`, `docs/sitemap.xml` — keep the sitemap in sync with blog posts.
- `migration/` — one-off scraper + extracted content from the old Google Sites (source
  material). `docs/handoff/` is the design handoff: **git-ignored, never commit, delete
  later**.

## Design system (from the handoff)

Blue brand `#13B0E5`, geometric primitives as section/identity glyphs, chunky 3D buttons
with hard offset shadows (no soft shadows). One sans (Inter), one mono (IBM Plex Mono).
Honor `prefers-reduced-motion`. Tokens + component CSS are in `assets/site.css`; the
original spec is in `docs/handoff/README.md` (local only).

## Deploy

Push to `main`; Pages serves `/docs` automatically. `.github/workflows/lighthouse.yml`
audits the live site on each push (target: A11y / Best Practices / SEO = 100).
