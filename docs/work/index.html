Apps

KRAIL

Sydney public transport shouldn't be stressful. KRAIL covers trains, buses, ferries, metro and light rail: real-time, accessible and open source. It is written in Kotlin Multiplatform with a Ktor backend.

I presented how it is built at Google I/O Extended Brisbane 2025.

Visit krail.app GitHub

A colour perception game built around Delta-E science. Find the outlier among near-identical hues. It starts forgiving and gets quietly brutal, and it ranks you by accuracy, not just speed.

Open source libraries and services

KRAIL-BFF

The Ktor backend behind KRAIL: trip planning over the NSW transport network, Protobuf contracts and a containerised deploy.

KRAIL-API-PROTO

Shared API data contracts in Protocol Buffers, the typed boundary between KRAIL's app and backend.

dhruva

A Kotlin Multiplatform location library for Android and iOS. Sanskrit-named, one API across platforms.

aagya

A Kotlin Multiplatform permission library for Android and iOS. Runtime permissions without the per-platform boilerplate.

How a build runs

  1. Plan. Read the designs and plan the work.
  2. Build. Write the code, one step at a time.
  3. Check. Review each step before the next.
  4. Learn. Note what went wrong for next time.
